# Интеллектуальная система обработки заказов

**Тема ВКР:** Разработка интеллектуальной системы обработки неструктурированных заказов на основе LLM и семантического поиска.

**Автор:** Дущенко Даниил Александрович. Индивидуальная работа.

Система предназначена для обработки текстовых заказов на продукты питания, поступающих в мессенджере. Она извлекает позиции и реквизиты заказа, сопоставляет названия с каталогом и уточняет неоднозначности у клиента. Целевой контур — создание подтверждённого заказа в Bitrix и последующая передача в 1С существующим механизмом обмена.
